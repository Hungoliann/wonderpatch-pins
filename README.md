# Wonderpatch Pins

Original promotional graphics for Wonderpatch's Redbubble designs, prepared for Pinterest.

- `pins/` holds 16 different 1000 x 1500 PNG promotional graphics.
- Images are paired in sets of two per design: artwork and product-context presentation.
- Sticker mockups are digitally created previews, not photos of shipped products.

**Image hosting:** After publishing this public repository on GitHub, raw assets use:

`https://raw.githubusercontent.com/<YOUR_GITHUB_USERNAME>/wonderpatch-pins/main/pins/01_adventure_clean.png`

Pinterest promotions should use the confirmed product URLs maintained separately in your campaign spreadsheet.
